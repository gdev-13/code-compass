# 👤 Personas

## Persona 1 - Gabriel, Desenvolvedor em Evolução

### Perfil

* 23 anos
* Desenvolvedor júnior
* Estuda React, Java e Spring Boot
* Possui conhecimentos básicos e intermediários em desenvolvimento web

### Objetivos

* Aprender conceitos de programação de forma consistente
* Desenvolver maior autonomia na resolução de problemas
* Entender quando utilizar determinadas tecnologias, métodos e recursos

### Dores

* Frequentemente esquece conceitos estudados anteriormente
* Tem dificuldade em identificar qual ferramenta ou abordagem utilizar para resolver um problema
* Muitas vezes recebe soluções prontas de ferramentas de IA sem compreender os conceitos envolvidos

### Necessidades

* Identificar rapidamente quais conceitos precisa estudar
* Receber direcionamento para documentações e materiais confiáveis
* Construir uma visão clara do próprio conhecimento ao longo do tempo

## Persona 2 - Ana, Estudante de Programação

### Perfil

* 19 anos
* Estudante de Análise e Desenvolvimento de Sistemas
* Está aprendendo programação web

### Objetivos

* Compreender os fundamentos antes de avançar para tópicos mais complexos
* Desenvolver confiança para criar projetos próprios

### Dores

* Não sabe quais tópicos estudar para implementar determinadas funcionalidades
* Sente-se perdida diante da quantidade de conteúdos disponíveis
* Tem dificuldade em transformar objetivos em pesquisas eficientes

### Necessidades

* Orientação sobre o que estudar primeiro
* Explicações sobre a relação entre conceitos e problemas reais
* Sugestões de uma sequência de aprendizado adequada

## Persona 3 - Carlos, Desenvolvedor em Transição

### Perfil

* 32 anos
* Desenvolvedor experiente em uma tecnologia específica
* Está migrando para um novo ecossistema ou framework

### Objetivos

* Identificar rapidamente os conceitos equivalentes na nova tecnologia
* Reduzir o tempo necessário para adaptação

### Dores

* Conhece a solução conceitual, mas não sabe como ela é aplicada na nova stack
* Perde tempo procurando documentações e recursos dispersos

### Necessidades

* Descobrir quais conceitos estudar em cada contexto
* Receber recomendações direcionadas para sua tecnologia de interesse
* Aproveitar conhecimentos já adquiridos durante a transição
